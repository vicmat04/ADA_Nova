# Export Consolidado Nacional (Informe Cuatrimestral → Avance Nacional)

Rebuild the "📥 Exportar Consolidado" button (`regionales_tab_module.py`, `exportar_excel`) so it exports every available per-infoplaza datum for the selected year + cuatrimestre, from Supabase only, with mandatory pagination.
Reference output validated by the user: `MUESTRA_Consolidado_Nacional_2026_C2.xlsx` (project root), generated by the prototype `C:\Users\vdominguez\AppData\Local\Temp\ada_probe\muestra_export.py` (outside the repo; port its logic, do not import it).

## Specs

- **S1** Scope: "quiero que ese botón pueda exportar toda la información posible de cada infoplaza del cuatrimestral que se seleccione". The period is the year + cuatrimestre selected in the tab (`get_selected_anio()` / `get_selected_cuat()`). Months: C1 = 1-4, C2 = 5-8, C3 = 9-12.
- **S2** Source: "lo que se exporta dede ese botón no vive en local, la fuente de la verdad está en supabase" and "para esta exportación no usaremos nada que venga de google sheet". Tables: `infoplazas`, `control_entrega_informes`, `informe_cuatrimestral_header`, `informe_capacitaciones`, `informe_otras_actividades`, `informe_servicios`, `resumen_demografico`, `resumen_servicios`, `resumen_tipo_usuario_genero`.
- **S3** Pagination: "si, la paginación en la consulta es MUY importante". Fetch every query in pages of 1000 (`Range` header + `Prefer: count=exact`). If the downloaded row count differs from the server total in `Content-Range`, the export must fail with a visible error and write no file.
- **S4** Meta: "se calcula multiplicando (total de computadoras x 48) * 4, eso da la meta del cuatrimestre de la infoplaza, para saber cuanto cumplió de ese 30% se usa (total de visitas del cuatrimestre x 30%) / meta del 30%". User-confirmed example: 10 PC → meta 1920; 600 visits → 600 × 0.3 / 1920 = **9.4%**. Visits = sum of `resumen_demografico.total` for the cuatrimestre months. Meta 0 → empty %.
- **S5** PC for the meta: "el encabezado, es más real y más seguro". Use `informe_cuatrimestral_header.cant_computadoras` of the period; if there is no header, fall back to `infoplazas.cant_computadoras`. Also show "PC Encabezado Informe", "PC Catálogo" and "Diferencia PC (Enc - Cat)" columns, plus a "Diferencias PC" sheet listing only the mismatches.
- **S6** "en la 3 vamos a dividir capacitaciones de otras actividades y cada una con sus totales". No combined "beneficiados" column.
- **S7** "pon la columna firmas, fotos y operando y dejala en blanco al exportar".
- **S8** "agrega una hoja con las infoplazas marcadas como cerradas y algunos detalles que tengas de ella". Closed means `estado` contains "cerrad" (the catalog value is "Cerrada Definitivamente"); closed infoplazas are excluded from the other sheets. Criterion text: "Estado del catálogo: <estado>".
- **S9** "IPS no va, lo que sea porcentaje lo quiero en formato de %, ejemplo 53.5%". Store percentages as fractions with the Excel number format `0.0%`.
- **S10** "deja todo lo que ya agregaste y no habíamos hablado". Keep all sheets of the sample, in this order: Resumen Regionales (with a TOTAL NACIONAL row), Directorio Nacional, Capacitaciones, Otras Actividades, Servicios Ofrecidos (✔/✘ matrix of the standard services + Total Ofrecidos + a "Servicios Personalizados" column joined with "; "), Visitas Mensuales, Uso de Servicios, Tipo Usuario y Género, Pendientes y No Entregan, Diferencias PC, Infoplazas Cerradas. Freeze the header row, add autofilter, auto-size columns (max 45).
- **S11** Columns and labels must match the sample file exactly (same sheet names, column names and order).
